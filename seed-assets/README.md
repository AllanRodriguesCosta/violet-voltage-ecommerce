# Imagens próprias ou licenciadas

Os SVGs em public/assets são ilustrações originais e genéricas criadas para esta demonstração. Não representam marcas comerciais. A ilustração de acessórios é um placeholder compartilhado.

Coloque aqui fotos JPEG, PNG ou WebP próprias ou com licença compatível; mantenha comprovação e atribuição da licença quando necessária. Esta pasta não é servida publicamente. Envie cada imagem pelo painel administrativo, botão **Imagem**, após cadastrar o produto. Máximo: 5 MB. SVG não é aceito no upload.

O seed usa apenas placeholders locais, é opcional e não envia arquivos desta pasta automaticamente ao Azure.
