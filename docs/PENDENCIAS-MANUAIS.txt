PARA QUE SERVE
--------------
O codigo e os testes unitarios sao feitos pelo Copilot, direto no repositorio
do GitHub (uma branch e um pull request por etapa, merge so com o CI verde).
Este arquivo lista o que o Copilot NAO consegue fazer a partir do GitHub e que
precisa ser feito no computador do Allan, por ele ou pelo Codex.
Ferramentas, contas e bibliotecas: docs/FERRAMENTAS-E-BIBLIOTECAS.txt.
Fotos de produtos novos: docs/FOTOS-PENDENTES.txt (53 fotos da etapa 18).

REGRAS PARA QUEM EXECUTAR (INCLUSIVE O CODEX)
--------------------------------------------
1. Cada tarefa tem um codigo (ex.: T01), um responsavel e um estado:
   [ ] pendente   [x] concluida   [!] bloqueada (anote o motivo).
   Responsavel: ALLAN, CODEX ou ALLAN/CODEX (qualquer um dos dois).
2. Nao altere codigo em src/, public/ ou tests/. Mudancas de codigo ficam com o
   Copilot: descreva o problema encontrado e o Allan repassa.
3. Nunca coloque senhas, chaves, URLs de banco ou o conteudo do .env em
   arquivos do repositorio, commits, prints ou mensagens. Use apenas o .env
   local (ignorado pelo Git) e as variaveis de ambiente do Render.
4. Ao concluir, marque a tarefa, anote data e resultado em uma linha
   ("Resultado: ...") e envie a alteracao deste arquivo em uma branch propria
   (ex.: codex/t03-lighthouse) com pull request para main.
5. Se um comando falhar, pare, anote a mensagem de erro principal e o comando
   usado. Nao tente "consertar" mudando codigo.

T03 [ ] CODEX - Lighthouse do site publicado
----------------------------------------------------------------------
Pendente desde a etapa 16. No terminal, na raiz do projeto (precisa de
internet; o npx baixa a ferramenta sem instala-la no projeto):
  npx lighthouse https://violet-voltage-ecommerce-1.onrender.com/ --preset=desktop --output=json --output-path=./lighthouse-home-desktop.json --quiet --chrome-flags="--headless"
  npx lighthouse https://violet-voltage-ecommerce-1.onrender.com/catalogo.html --output=json --output-path=./lighthouse-catalogo-mobile.json --quiet --chrome-flags="--headless"
Antes, abra o site uma vez no navegador e espere carregar (o plano gratuito do
Render "dorme" e a primeira visita demora; isso distorce a medicao).
Anote em "Resultado" as quatro notas (Performance, Accessibility, Best
Practices, SEO) de cada pagina e os 3 principais itens apontados.
NAO envie os arquivos .json para o repositorio (apague-os depois).
