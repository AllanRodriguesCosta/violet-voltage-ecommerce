O QUE FAZER
-----------
1. Salve cada foto com EXATAMENTE o nome indicado na linha, dentro de
   seed-assets/produtos-violet-voltage/<subpasta>/ (ex.: .../guitarras/).
   Essa pasta NAO vai para o GitHub (esta no .gitignore).
2. Formato: PNG de verdade (JPG ou WebP renomeado para .png e recusado).
   Quadrada (1:1), de 800x800 a 1200x1200 px, produto inteiro e centralizado,
   fundo branco ou transparente, sem textos, precos ou marcas d'agua.
   Ate 1 MB por foto (ideal: ate 500 KB). Para reduzir o peso sem custo:
   https://squoosh.app (opcao OxiPNG) ou https://tinypng.com.
3. Use apenas imagens que voce tenha direito de usar: fotos proprias, material
   de divulgacao com permissao ou imagens com licenca livre.
4. Marque [x] na linha de cada foto pronta (pode enviar este arquivo
   atualizado em um pull request).
5. Confira a pasta: npm run fotos:conferir
   (mostra quantas fotos estao prontas, quais faltam, PNGs invalidos e
   arquivos acima de 1 MB; nao altera nada).
6. Carregue no banco, como na tarefa T06 de docs/PENDENCIAS-MANUAIS.txt:
   - todas as fotos prontas:  npm run seed
   - so parte delas:          npm run seed -- --parcial
     (carrega os produtos que ja tem foto e lista os que ficaram de fora;
     rode de novo quando chegarem mais fotos, sem duplicar nada)
   Enquanto o seed nao rodar, os produtos novos nao aparecem no site publicado.
