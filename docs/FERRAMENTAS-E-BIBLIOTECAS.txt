[MANUAL] Fotos (T05): qualquer editor que exporte PNG. Para reduzir o peso,

         https://tinypng.com.

Comandos uteis (na raiz do projeto):
  npm ci             instala exatamente o que esta no package-lock.json
  npm test           testes (o teste PostgreSQL usa PGlite, ja nas devDependencies)
  npm run lint       ESLint
  npm run fotos:conferir  confere as fotos de seed-assets sem alterar nada
  npm run seed       carga do catalogo (precisa das fotos; ver T06)
  npm run seed -- --parcial   carrega so os produtos que ja tem foto
  npm run agente:eval  acerto do assistente em frases fora do treino
  npm run db:migrate cria/confere as tabelas

2. CONTAS E SERVICOS GRATUITOS
------------------------------
[OK]     GitHub: repositorio e CI (GitHub Actions, workflow quality.yml).
[OK]     Render (plano gratuito): hospeda o site. As variaveis de ambiente do
         item 1 ficam em Render > servico > Environment.
[OK]     Supabase (plano gratuito): banco PostgreSQL. As imagens dos produtos
         ficam no proprio banco. Nao expor o schema violet_voltage pela Data API.
[MANUAL etapa 25] Google AI Studio (Gemini, plano gratuito), tarefa T07:
         1. Entrar em https://aistudio.google.com com uma conta Google.
         2. "Get API key" > criar chave. NAO ativar faturamento (billing) nem
            cadastrar cartao: sem isso nao ha cobranca, so limites de uso.
         3. Colocar a chave como GEMINI_API_KEY no .env local e no Render
            (Environment). Nunca no codigo, em commits ou no chat.
         4. Lembrete: no plano gratuito o Google pode usar o conteudo enviado
            para melhorar seus produtos. O assistente so envia a pergunta e
            dados do catalogo, nunca dados pessoais.
         Sem a chave o assistente continua funcionando com a PLN local.
